# Naruto 5e

A standalone Naruto-inspired tabletop system built on a 5e-style mechanical foundation.

**Repository status:** Public Playtest / Shared Rules Source

## What belongs here

This repository contains only the material intended to function as the shared Naruto 5e rules and player-facing foundation.

- `mechanics/` — shared Naruto 5e mechanics
- `players/` — isolated player/character profiles
- `pvp/` — player-vs-player protocol
- `references/` — locked reusable mechanical references
- `story-mode/` — intentionally empty until the story foundation is assembled

## Source-of-truth rule

The newest explicitly established rule takes precedence over older drafts. Do not silently resolve contradictions by inventing mechanics.

Use these labels when needed:

- **ESTABLISHED** — currently established shared rule
- **PLAYTEST / DRAFT** — usable or proposed, but not fully locked
- **PROVISIONAL** — temporary ruling for a specific situation
- **UNKNOWN** — not yet defined
- **RETIRED** — superseded and not active

## Important separation

Matthael's personal campaign state is intentionally not part of this public repository's shared rules foundation.

A player's character must not inherit another player's abilities, equipment, progression or story state unless explicitly included in that character's own profile or PvP snapshot.
