# Naruto 5e — Player Profiles

This directory contains characters created for players outside Matthael's personal campaign state.

## Separation rule

Each player/character gets a separate directory:

`players/<character-or-player-id>/`

A player profile must never silently inherit Matthael's abilities, equipment, story state, prepared effects, summons or progression.

Character status labels:
- `DRAFT` — still being created
- `PLAYTEST` — usable for testing
- `VALIDATED` — checked against the current shared rules
- `RETIRED` — no longer active

Do not silently repair or invent missing mechanics. Flag them for review.

## PvP readiness

A character may enter PvP only when the profile contains enough information to resolve its actions consistently, including level/tier, HP, Chakra, Stamina, ATK, DEF, CONTROL, affinities, known techniques, technique costs, relevant reactions/passives and established special mechanics.

The shared `mechanics/` rules are the source of truth. Character-specific rules belong only in that character's profile.
